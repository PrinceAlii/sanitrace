# 0007: Report diff

Status: Accepted
Target: 0.4.0
Depends on: 0004

## Problem

A user often runs the same prompt twice, with two model settings or two client
versions. The reports look alike, but the turn order and the tool output can
diverge. Comparing two long Markdown reports by hand is slow. A report does not
record a turn identifier, so a tool cannot align turns after an insertion.

## Goals

- Add a `sanitrace diff <a.md> <b.md>` command for reports generated by
  sanitrace.
- Emit a stable turn identifier in every rendered turn.
- Report unchanged, changed, added, and removed turns.
- Show the changed lines for a changed turn.
- Support Markdown output by default and `--json` output for tooling.
- Exit 0 when the transcripts are identical, 1 when they differ, and 2 for
  usage or I/O errors.

## Non-goals

- Diffing raw session logs. Parse the logs first and diff the reports.
- Three-way merge, patch application, or a merge tool.
- Comparing metadata rows, narrative sections, or the redaction table.
- Diffing reports from another tool.
- A graphical interface.
- Semantic comparison of prose. A changed character is a changed turn.

## Proposal

### Turn markers

`renderTurn()` in `src/render.js` writes a marker before the heading:

```markdown
<!-- sanitrace:turn:2 -->
### 2. assistant

The answer.
```

The marker index is the turn position in the source session. It is not an
identifier because an inserted turn changes later indices.

After redaction, `sanitize()` replaces each marker with a content identifier:

```markdown
<!-- sanitrace:turn:2:6f1c2a9d4b70 -->
### 2. assistant
```

The identifier is the first 12 lowercase hexadecimal characters of
`SHA-256(role + "\n" + normalized body)`. The body is the text after the
heading, with LF line endings, trailing whitespace removed from each line, and
leading and trailing blank lines removed. The hash runs over the redacted text,
so it does not expose a detected secret.

`render()` keeps the placeholder form. `sanitize()` calls `stampTurnIds()`,
which is also exported from `src/render.js`, before it runs the verify pass.
The renderer writes `<!-- sanitrace:turn:end -->` after the last turn. The end
marker lets `stampTurnIds()` find the last body without scanning the footer.

`render()` emits the end marker even when the transcript has no turns.

### Diff command

```console
$ sanitrace diff old.md new.md
$ sanitrace diff old.md new.md --json
$ sanitrace diff old.md new.md -o diff.md
```

The command reads both files, extracts the transcript between the turn markers,
and recomputes every turn identifier from the report text. A report without turn
markers is rejected with exit 2 and a message that names the file and asks for a
report generated by sanitrace 0.4.0 or later.

The recomputed identifier is authoritative. A stale identifier in a hand-edited
report does not stop the diff.

### Alignment

The command aligns turns with a longest common subsequence over the identifiers.
Turns outside the common subsequence form gaps. Within a gap, the command pairs
turns by position:

- a gap turn in both reports with the same role becomes `changed`
- a gap turn in both reports with different roles becomes `removed` and `added`
- a gap turn only in A becomes `removed`
- a gap turn only in B becomes `added`

The output keeps the order of A, then reports added turns at the position where
they occur in B.

A changed turn compares its lines. It prints the common prefix and suffix as
context and marks the remaining lines with `-` and `+`. It does not compute a
minimal edit script. The full body is shown for an added or removed turn.

### Markdown output

```markdown
# Report diff

| Report | Turns |
| --- | --- |
| `old.md` | 8 |
| `new.md` | 9 |

| Result | Count |
| --- | --- |
| Unchanged | 6 |
| Changed | 1 |
| Added | 1 |
| Removed | 0 |

## Changed turn 3

`1a2b3c4d5e6f` → `7a8b9c0d1e2f`

~~~diff
 common line
-old line
+new line
 common line
~~~

## Added turn 9

`3c4d5e6f7a8b` assistant

~~~markdown
Full body.
~~~
```

The fence uses at least three tildes or backticks and grows past the longest
run in the body. The report paths appear as code spans. The summary table uses
the same style as the report tables.

A report with zero turns on both sides prints the summary and the line
`No transcript differences.`.

### JSON output

```json
{
  "a": { "path": "old.md", "turns": 8 },
  "b": { "path": "new.md", "turns": 9 },
  "summary": { "unchanged": 6, "changed": 1, "added": 1, "removed": 0 },
  "turns": [
    {
      "status": "changed",
      "a": { "index": 3, "role": "assistant", "id": "1a2b3c4d5e6f", "text": "old body" },
      "b": { "index": 3, "role": "assistant", "id": "7a8b9c0d1e2f", "text": "new body" },
      "diff": [
        { "type": "context", "text": "common line" },
        { "type": "removed", "text": "old line" },
        { "type": "added", "text": "new line" }
      ]
    }
  ]
}
```

An unchanged entry has `a` and `b` objects with the same `id` and no `diff`.
An added entry has only `b`. A removed entry has only `a`. The `path` fields
match the arguments as written.

### Exit codes

| Condition | Exit |
| --- | --- |
| No differences | 0 |
| At least one changed, added, or removed turn | 1 |
| Missing argument, unreadable file, or report without markers | 2 |

The command writes the Markdown or JSON before it sets exit code 1.

### CLI validation

`diff` accepts `--json`, `--out`, `-o`, `--help`, and `--version`. Other flags
are ignored unless they change global parsing. A positional count other than
two exits 2 with:

```text
usage: sanitrace diff <a.md> <b.md> [--json] [-o <file>]
```

The command does not load `.sanitrace.json` and does not run detectors. It reads
only the two report files.

## Behavior

- CRLF and LF reports compare equal after line-ending normalization.
- Trailing whitespace on a line is ignored. Interior whitespace is compared.
- The transcript must start at a `<!-- sanitrace:turn:N... -->` marker. Text
  before the first marker is ignored.
- A marker must be followed by a heading of the form `### <n>. <role>`. A
  malformed marker or heading exits 2.
- The recomputed identifier uses the heading role and the body. It does not use
  the marker index.
- Empty bodies are valid.
- The command does not read the input session logs and does not create a
  mapping.

## Failure modes

| Condition | Result |
| --- | --- |
| No arguments or one argument | Exit 2, usage |
| Three reports | Exit 2, `unexpected argument` |
| Missing file | Exit 2, `cannot read report <path>: ...` |
| A report without turn markers | Exit 2, names the file and asks for 0.4.0 |
| Marker without a heading | Exit 2, names the file and the marker |
| Unreadable output path | Exit 2, write error |
| A report with zero turns | Exit 0 when both reports have zero turns |

## Security

The command reads reports that sanitrace already redacted. It does not run
detectors again. The diff output repeats report text, so it has the same
sensitivity as the reports. The command does not read session logs, does not
write a mapping, and does not use the network.

A turn identifier is a hash of redacted content. It is not a secret and is not
a replacement for the verify pass.

## Test plan

Unit tests:

- `stampTurnIds()` adds an identifier to every marker and leaves the end marker.
- The identifier is stable across LF and CRLF input.
- The identifier changes when the role or body changes.
- The identifier ignores trailing whitespace and blank lines at the edges.
- `parseReport()` accepts a report with markers and returns the role, index,
  body, and identifier.
- `parseReport()` rejects a report without markers, a marker without a heading,
  and a malformed heading.
- `diffReports()` returns unchanged for identical turns.
- A changed turn returns `changed` and a line diff.
- An inserted turn returns `added` at the correct position.
- A removed turn returns `removed` at the correct position.
- A replaced turn with a different role returns `removed` and `added`.
- Reordered turns produce a stable result.
- Zero-turn reports return an empty turn list.

CLI tests:

- `diff` on identical reports exits 0 and prints `No transcript differences.`
- `diff` on changed reports exits 1 and prints the changed line.
- `diff --json` returns the documented shape and exits 1.
- `diff -o` writes the output file.
- `diff` with a missing file exits 2.
- `diff` with a 0.3.0 report exits 2 and names the file.
- `diff` with one argument exits 2 with the usage line.
- A report path with spaces works.
- The command ignores a malformed `.sanitrace.json` in the working directory.

Report tests:

- Every generated report contains a marker for each kept turn and one end
  marker.
- The marker identifier matches `stampTurnIds()` over the report body.
- Existing report snapshots are regenerated with markers and the current
  version.
- The report budget still closes fences and details blocks after markers are
  added.

Cross-platform checks:

- CRLF reports from Windows compare equal to LF reports.
- Paths with spaces and backslashes work on Windows.
